Checking

famulus-astra check says what can be said of each kind of text. Levels presuppose one another; the report names the level reached, every failed check with its reason and every gap. Nothing passes by default.

Model

level what is checked
well-formed the text parses; names are unique and defined before use; types match; no value, no source, no statement of another kind
constructible every object has a solution in every sampled configuration of the parameter space and the states
astronomical one observer; a body; an observable direction from the observer to the body; a declared frame
kinematic a kinematic variable that reaches a body through the construction
consistent the stated propositions hold in every sampled configuration
documented attributed, witness, author; a meaning for every symbol and object

Parametrisation

level what is checked
complete every parameter of the model has a value
admissible every value lies in its range
attested every value has a source fr:… or a gap "…"; whose values they are and who wrote the text is said

Superposition, figure

A superposition is checked as a model, with superposed in place of the astronomical levels: the members’ observers are identified. A figure is drawable when its values and state give every drawn object a place, and labelled when every drawn object has a meaning or a symbol.

Exit code

famulus-astra check <id> exits 1 unless the text passes all its levels (--allow-incomplete lifts that), so it can gate a build. --json gives the report as data (build/<id>/check.json).
